Як запустити
Треба встановити бібліотеки. Відкрий термінал (командний рядок) і встав цей рядок:

pip install pulp pandas openpyxl
Запуск. Збережи код у файл (наприклад, agro.py). У терміналі напиши:

python agro.py
Результат. Скрипт створить папку excel і покладе туди файл із датою в назві.

опис
1. Відповіді Головна сторінка. Тут зразу видно загальну суму грошей на всю логістику і чи є якісь проблеми.
2. Оптимізований маршрут Це готовий план для логіста. Рядок за рядком: який день, з якого поля, на який елеватор і скільки машин (тонн) треба відправити.
3. Аналіз маршрутів Тут видно, які дороги завантажені найбільше. Сортування від найпопулярніших напрямків до тих, де їздять мало.
4. Баланс по днях Загальна картина "з вертольота". Скільки всього зібрали за день, скільки прийняли і скільки лежить на складах по всій компанії разом.
ватори Детально по кожному елеватору. Можна глянути, чи не переповнюється конкретний склад і скільки зерна він приймає щодня.
6. Ефективність Підсумок роботи елеваторів. Хто "пахав" найбільше (пропустив через себе купу зерна), а хто стояв напівпорожній.
7. Витрати Бюджет по днях. Скільки грошей піде на перевезення в перший день, скільки в другий і так далі. Зручно для фінансистів.
8. Вузькі місця (ця вкладка з'явиться тільки якщо є проблеми) Список ризиків. Сюди потрапляють елеватори, які працюють на межі своїх можливостей (завантажені на 90%+). Це сигнал, що там може бути черга або збій.
